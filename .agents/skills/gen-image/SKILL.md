# gen-image

## 定位

用户给出图片需求，Agent 负责把需求变成可交付的 PNG/SVG 资产。Agent 以用户提供的说明为准，其余细节逐项向用户提问确认；方案经用户确认后，Agent 完成脚本编写、渲染、自检与交付。

## 协作方式

1. **先澄清，后生成。** 动手前把必问清单逐项与用户核对，请用户确认或选择默认值。
2. **方案先行。** 生成前先向用户简述部件拆分与关键参数（尺寸、风格、配色、输出路径），确认一致后再渲染。
3. **交付验收。** 每轮生成后把 HTML、PNG、预览图的路径连同自检数据一起列出，请用户看图；按用户意见修改参数后重新生成，直到用户认可。

## 必问清单

| 项目 | 提问内容 | 默认建议 |
|---|---|---|
| 主体 | 画什么、什么动作、什么朝向、什么视角 | 跟随用户描述 |
| 画布 | 宽高与比例 | 64×64 |
| 留白 | 边缘透明留白量 | 每边 8px |
| 风格 | 像素风 / 扁平 / 线稿 / 渐变质感 | 像素风 |
| 背景 | 透明或指定颜色 | 透明 |
| 配色 | 主色、点缀色或参考图 | 灰蓝金属 + 锈橙 |
| 细节 | 用户点名要在画面里的元素 | 全部保留 |
| 输出 | 格式、命名、保存目录 | 与源 HTML 同名 |

## 生成步骤

### 1. 澄清需求
按必问清单收集信息，一次列全所有提问，每条给默认值。用户确认后进入部件设计。

### 2. 拆部件
把对象拆成一份部件清单，例如：主体底盘、侧翼、引擎、核心舱、传感灯、钻头、锈迹、破损区。每个部件对应一个 SVG `<g>` 组，先列底层部件，后列顶层细节。对称部件用 `<g transform="translate(W,0) scale(-1,1)">` 镜像复用同一组几何，保证两侧一致。调色板集中定义在脚本顶部，改色只改一处。

### 3. 拼装 SVG
用 `rect`、`circle`、`ellipse`、`polygon`、`path` 组合出各部件。部件的组合顺序代表层叠关系，后画的组覆盖先画的组。

### 4. 用 SVG 后处理表达质感
描边、圆角、渐变、阴影、透明度由 SVG 直接完成：

- 主体轮廓统一描边，画面立即有辨识度。
- 圆角半径给面板柔和感。
- 线性渐变做分面过渡。
- `feDropShadow` 或 CSS `filter: drop-shadow` 做柔和投影。
- 半透明色块叠出烟尘、污渍与锈斑。
- 光照方向一致时，部件左上边缘画浅色条、右下边缘画深色条，形成立体感。

### 5. 包进 HTML
`html, body` 的宽高等于画布像素，`background: transparent`，SVG 内联并铺满画布，`viewBox` 与画布一致。像素风时给 SVG 加 `shape-rendering="crispEdges"` 并保持坐标取整。页面自包含，文字使用系统字体。

### 6. 渲染与自检
用技能自带脚本渲染透明 PNG 与放大预览，并阅读脚本输出的自检数据（尺寸、内容像素、四边留白）确认画面符合约定。

### 7. 交付与迭代
向用户提交文件路径与自检摘要，请用户验收。用户指出问题后，把意见映射到对应部件的参数上修改脚本，重新渲染，直到用户满意。

## 边界情况

- 用户描述含抽象词汇（酷、可爱、质感）：请用户换成具体元素或提供参考图。
- 画布小、细节多：合并次要部件，保留主体轮廓，或建议用户改用更大画布。
- 像素风细节小于 2px 会显得模糊：细节尺寸保持 2px 以上。
- 需要透明背景：渲染脚本默认输出透明 PNG。
- 留白尺寸需要调整：按自检数据调整画布内整体偏移量后重渲染。
- 文字入图：先向用户确认文案与字体，提示渲染结果依赖本机安装的字体。
- 浏览器可用性：通过 `CHROME_PATH`、`BROWSER_PATH` 或 `--browser <路径>` 指向 Chrome / Edge / Chromium 完成渲染。
- 本流程面向矢量风格，写实摄影类需求请用户提供素材或改用其他工具。
- 需求中途变化：请用户指出具体部件，Agent 修改对应参数并重新生成。

## 目录结构

```
.agents/skills/gen-image/
├── SKILL.md
└── scripts/
    ├── render-png.js   # 通用渲染 + 自检脚本
    └── example.html    # 最小示例，用于验证流水线
```

## 快速上手

```bash
# 把示例渲染为 64x64 透明 PNG 与 8 倍预览
node .agents/skills/gen-image/scripts/render-png.js \
  .agents/skills/gen-image/scripts/example.html \
  temp/gen-png/example.png --size 64 --preview 8
```

渲染脚本默认输出透明背景 PNG，并打印画布尺寸、内容像素数与四边留白，作为生成侧的客观自检依据。
